# The inputs of the firmware hash, the build ID that `version` prints and manifest.json
# records as `build_id`: one git pathspec per line, from the repository's root. The ID is
# the first 12 hex digits of `git hash-object` over `git ls-files -s -z` of these paths,
# so it names the blobs that build app.bin, loader.bin, image.bin and the installer's
# .uapp, and a commit that touches nothing here keeps it. `-dirty` follows it when any of
# these paths has an uncommitted change or an untracked file.
# tools/firmware_build.py and apps/standalone-boot/build.rs both compute it from this list.
#
# Left out, because none of it reaches a binary: gate.json and the other release/ docs,
# site/, the workflows (firmware.yml's SDK revision is toolchain.json's, which the recipe
# enforces), the host tools and their tests, and the packaging half of
# tools/release-build.py. This list itself is left out too: what it selects is hashed.

# The loader, the first 32 KiB of image.bin.
apps/wrist-loader

crates

vendor
